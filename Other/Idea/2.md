# Ngày 2 — CRUD, Calendar cơ bản và Task
## 1. Hiểu CRUD
**CRUD là 4 thao tác cơ bản với dữ liệu:**
Create  → Tạo
Read    → Đọc
Update  → Sửa
Delete  → Xóa

Trong project này:
Events
Tasks
TaskItems

đều cần CRUD.
Ví dụ với Event:
Create → Tạo Event mới
Read   → Hiển thị Event lên Calendar
Update → Sửa thời gian/tên/màu
Delete → Xóa Event

Không cần làm tất cả cùng lúc. Nên bắt đầu với Event để hiểu quy trình, sau đó áp dụng tương tự cho Task.
## 2. Tổ chức phần truy cập Database
Không nên viết toàn bộ SQL trực tiếp lẫn vào phần giao diện.
Tối thiểu nên tách tư duy thành:
Giao diện
   ↓
C# xử lý
   ↓
Database Access
   ↓
SQL Server

Ví dụ khi người dùng bấm "Tạo Event":
User
 ↓
Form nhập Event
 ↓
C#
 ↓
INSERT INTO Events
 ↓
SQL Server

Khi Calendar cần hiển thị Event:
Calendar
 ↓
C#
 ↓
SELECT FROM Events
 ↓
SQL Server
 ↓
C#
 ↓
HTML

Chưa cần xây dựng một kiến trúc quá phức tạp. Mục tiêu là code dễ sửa trong 4 ngày.
## 3. Làm CRUD cho Event
### 3.1. Create Event
Tạo giao diện nhập:
```
Title
Description
StartTime
EndTime
Color
```

Khi người dùng nhấn:
Create

C# nhận dữ liệu và thực hiện INSERT.
Cần kiểm tra:
Title không được rỗng
StartTime phải có
EndTime phải có
EndTime > StartTime

### 3.2. Read Event
Khi mở Calendar:
SELECT ...
FROM Events
WHERE UserId = ...

Sau đó lấy danh sách Event và đưa lên Calendar.
Ở giai đoạn đầu chỉ cần hiển thị đúng dữ liệu.
Chưa cần hiệu ứng hoặc giao diện phức tạp.
### 3.3. Update Event
Cho phép thay đổi:
- Tên.
- Mô tả.
- Thời gian.
- Màu.
**Đặc biệt:**
Khi Event/Task thay đổi thời gian, database cũng phải được cập nhật.

### 3.4. Delete Event
Cho phép xóa Event.
Sau khi xóa:
Database không còn Event
        ↓
Calendar không còn Event

Có thể bắt đầu với Calendar theo một tuần.

Mỗi cột tương ứng với một ngày.
Mỗi hàng tương ứng với một khoảng thời gian.
## 5. Quy đổi thời gian thành vị trí trên giao diện
Đây là phần cần hiểu kỹ vì sau này còn dùng cho Drag Task và Zoom.
Ví dụ quy định:
1 giờ = 60 pixel

thì:
08:00 → top = 0px
09:00 → top = 60px
10:00 → top = 120px

Nếu Task bắt đầu lúc:
09:30

thì:
top = 90px

Tương tự với chiều cao:
Task: 09:00 → 11:00
duration = 2 giờ

height = 2 × 60
       = 120px

Như vậy một Task có thể được biểu diễn:
top    = StartTime → vị trí Y
height = Duration  → chiều cao
left   = Day       → vị trí X

Đây là nền tảng để biến dữ liệu Database thành Calendar trực quan.
## 6. Hiển thị Event lên Calendar
Sau khi có Grid và dữ liệu Event:
Event
09:00 → 10:30

C# hoặc JavaScript phải xác định:
Ngày nào?
Bắt đầu lúc nào?
Kết thúc lúc nào?
Màu gì?
Tên gì?

Sau đó đặt Event vào đúng vị trí.
Ví dụ:
        Monday

08:00
09:00 ┌───────────────┐
      │ Họp nhóm      │
10:00 └───────────────┘
11:00

Mục tiêu cuối bước này:
Dữ liệu trong SQL Server có thể xuất hiện đúng vị trí trên Calendar.

## 11. Bắt đầu Drag Task
Task cần có khả năng kéo trên Calendar.
Ví dụ:
14:00 → 16:00

kéo xuống:
15:00 → 17:00

thì:
StartTime = 15:00
EndTime   = 17:00

và sau đó cập nhật Database.
11.1. Quy trình Drag
Có thể chia thành:
Mouse Down
    ↓
Bắt đầu Drag
    ↓
Mouse Move
    ↓
Tính vị trí mới
    ↓
Mouse Up
    ↓
Xác định thời gian mới
    ↓
UPDATE Tasks

Không cần làm Drag hoàn hảo ngay lần đầu.
**Ưu tiên:**
1. Kéo được.
2. Task thay đổi vị trí.
3. Xác định được thời gian mới.
4. Lưu được vào Database.
Sau đó mới xử lý các trường hợp đặc biệt.
